# 🚀 Sobre o projeto

O **Personal Finance API** é uma aplicação backend desenvolvida para simular um sistema de gerenciamento financeiro pessoal.

O projeto foi construído com **Java e Spring Boot**, utilizando uma arquitetura em camadas para organizar responsabilidades e facilitar a manutenção e evolução da aplicação.

Além da implementação técnica, o projeto faz parte da minha jornada de aprendizado em desenvolvimento backend, com foco em práticas e tecnologias utilizadas no ecossistema Spring.

---

# 🎯 Objetivos

Este projeto foi desenvolvido para:

- Aprimorar conhecimentos em Java e Spring Boot
- Praticar o desenvolvimento de APIs REST
- Aplicar arquitetura em camadas e separação de responsabilidades
- Trabalhar com persistência de dados relacionais
- Praticar autenticação e segurança de APIs
- Aplicar validação e tratamento de exceções
- Documentar e testar endpoints de uma API REST
- Construir um projeto completo para portfólio

---

# 🧱 Arquitetura da aplicação

O projeto utiliza uma **arquitetura em camadas**, buscando manter as responsabilidades organizadas e o código desacoplado.

### Estrutura principal

```text
Controller
Service
Repository
DTO
Entity
Security
```

### Conceitos aplicados

- APIs REST
- DTOs para transferência de dados
- Separação de responsabilidades
- Persistência com Spring Data JPA
- Modelagem de entidades e relacionamentos
- Arquitetura em camadas
- Validação de dados
- Tratamento global de exceções
- Autenticação e autorização
- Boas práticas de desenvolvimento backend

# 🔐 Segurança

A API possui autenticação baseada em **Spring Security e JWT**.

O fluxo de autenticação inclui:

- Cadastro de usuários
- Login
- Geração de token JWT
- Validação do token nas requisições protegidas
- Proteção de endpoints conforme autenticação do usuário

# 📖 Documentação da API

A API utiliza **Swagger/OpenAPI** para documentação e exploração dos endpoints.

Quando a aplicação estiver em execução localmente, a documentação pode ser acessada em:

```text
http://localhost:8080/swagger-ui.html
```

> O endereço acima é local e funciona somente enquanto a aplicação estiver sendo executada na máquina.

---

# 🗄️ Banco de dados

O projeto utiliza **PostgreSQL** para persistência dos dados.

A aplicação utiliza **Spring Data JPA e Hibernate** para o mapeamento objeto-relacional e acesso aos dados.
