# 🚀 Sobre o projeto

O **Personal Finance API** é uma aplicação backend desenvolvida para simular um sistema moderno de gerenciamento financeiro pessoal.

A proposta do projeto é construir uma API REST organizada, escalável e alinhada com práticas utilizadas no mercado, aplicando conceitos fundamentais de engenharia de software e desenvolvimento backend.

Além da implementação técnica, este projeto também faz parte da minha jornada pública de aprendizado como estudante de Software Engineering / Backend Development.

---

# 🎯 Objetivos

Este projeto foi criado para:

- Aprimorar conhecimentos em Java e Spring Boot
- Praticar arquitetura de APIs REST
- Aplicar boas práticas de desenvolvimento backend
- Entender organização em camadas
- Trabalhar com persistência de dados
- Evoluir conceitos de modelagem e estruturação de sistemas
- Construir um projeto real para portfólio

---

# 🧱 Arquitetura da aplicação

O projeto segue uma arquitetura em camadas para manter organização, desacoplamento e escalabilidade.

## Estrutura principal

```bash
Controller 
Service
Repository
DTO
Entity
```

## Conceitos aplicados

- REST API
- DTO para transferência segura de dados
- Separação de responsabilidades
- Persistência com Spring Data JPA
- Modelagem de entidades
- Organização escalável de código
- Tratamento de dados sensíveis
- Boas práticas de backend

# ⚙️ Tecnologias utilizadas

| Tecnologia | Objetivo |
|---|---|
| Java | Linguagem principal |
| Spring Boot | Desenvolvimento da API |

| Maven | Gerenciamento de dependências |
| Lombok | Redução de código boilerplate |
